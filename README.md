# Кейсы по Авито — Артём Соколов

Статическая витрина результатов по ведению кабинетов Авито. По каждому проекту — выгрузка
статистики из раздела «Аналитика → Статистика» того кабинета, из которого взяты цифры.

**Сайт:** https://moss-sys.github.io/avito-portfolio/

| Просмотров | 3 млн+ |

| Опубликованных объявлений | 200 000+ |

## Что внутри

- `index.html` — вся страница: сетка карточек кейсов со скриншотом, фильтром по категориям
  и сортировкой. Клик по кадру открывает полноразмерные скриншоты. Ничего не подгружается
  со сторонних доменов — шрифт и изображения лежат рядом.
- `img/` — 86 кадров статистики в WebP. Имя файла = номер кейса.
- `fonts.css` — Onest подмножествами latin + cyrillic, вшит в base64.

## Правила публикации данных

Названия компаний-клиентов не публикуются: указаны только ниша и период. На нескольких кадрах
название аккаунта закрыто плашкой. Цифры приведены как есть, без пересчёта.

## Пересборка

Данные кейсов и конвейер сборки — в `build.py` (не в этом репозитории).
Команда: `python3 build.py --site <папка>` — кладёт `index.html` и пережатые кадры в `img/`.
